# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub Security Advisories:
https://github.com/ruizemanuel/ripio-community-mcp/security/advisories/new

Please don't open public issues for security problems. You'll get a first response within 7 days.

## In scope

- Anything that could make the server send a request other than GET, talk to a host other than `api.ripio.com`, or leak API keys.
- Supply-chain issues in the published npm package or the `.mcpb` bundle.

Problems in Ripio's own API or official MCP server are out of scope; please report those to Ripio.

## Supported versions

Only the latest 0.x release receives fixes.
